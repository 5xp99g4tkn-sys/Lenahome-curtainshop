# LENA HOME

Захиалгат хөшгийн вэбсайт: даавууны цуглуулга, өнгөний кодын хайлт, хөшгийн үнэ тооцоолуур (Монгол / English).

## Файлууд
- `index.html` — хуудасны бүтэц
- `style.css` — загвар
- `script.js` — даавууны өгөгдөл, хайлт, тооцоолуур

## Ажиллуулах
`index.html` файлыг хөтөч дээр нээнэ. GitHub Pages: Settings → Pages → Branch: main / root.

## Анхаарах
- Үнэ тооцоолуурын тохиргоо (оёдол, карниз, угсралт гэх мэт) зөвхөн хөтөч дээр хадгалагдана. Жинхэнэ админ самбар, өгөгдлийн сан (Supabase) хараахан холбогдоогүй.
- Даавууны албан ёсны swatch зураг ороогүй. Өнгөний ойролцоо тод нь зөвхөн урьдчилсан харагдац.
- Хүсэлтийн форм серверт илгээхгүй.
